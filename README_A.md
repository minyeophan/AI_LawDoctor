## 🔍 RAG 기반 AI 분석

AI 법률 닥터는 계약서 분석의 신뢰도를 높이기 위해
**전문가 교정 사례와 관련 법령 데이터를 활용한 RAG 기반 분석 구조**를 적용했습니다.

[RAG 기반 AI 분석 메커니즘]<img width="1168" height="654" alt="스크린샷 2026-09-24 034613" src="https://github.com/user-attachments/assets/1db4951a-1f28-45ea-a1e9-ce8c98c662a3" />

### 핵심 기술

| 구분 | 구성 요소 | 역할 |
|---|---|---|
| 전문가 데이터 | **계약 유형 필터링** | 상가·원룸 등 계약 유형에 맞는 교정 사례를 우선적으로 검색합니다. |
| 전문가 데이터 | **Embedding Anchor** | 조항 핵심 키워드와 전문가 의견을 결합하여 검색 정확도를 높입니다. |
| 법령 데이터 | **Gemini Vector Embedding** | 계약서 텍스트를 벡터로 변환하여 의미 기반 검색에 활용합니다. |
| 법령 데이터 | **Qdrant Hybrid Search** | Dense·Sparse 검색을 함께 사용하여 관련 법령을 검색합니다. |
| 법령 데이터 | **MongoDB** | 검색된 법령의 원문 정보를 조회합니다. |
| AI 분석 | **Gemini API** | 계약서 원문과 검색된 전문가 교정 사례 및 관련 법령 정보를 바탕으로 위험 조항과 개선안을 분석합니다. |
