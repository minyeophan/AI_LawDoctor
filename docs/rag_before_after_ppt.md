# RAG 적용 전후 비교 PPT 자료

## 슬라이드 1. RAG 데이터 구축 현황

| 항목 | 수치 |
|---|---:|
| 기존 전문가 교정 데이터 | 7개 |
| 신규 추가 데이터 | 23개 |
| 총 RAG 저장 데이터 | 30개 |
| RAG 적용 후 비교 파일 | 7개 |

핵심 문장:

> 전문가 검토 분석본을 RAG에 추가하여 총 30개의 교정 데이터를 기반으로 AI 분석 품질을 개선하였다.

## 슬라이드 2. RAG 적용 전후 비교 방법

| 구분 | 내용 |
|---|---|
| 비교 기준 | 전문가 검토본 |
| RAG 전 결과 | 기존 AI 의견 |
| RAG 후 결과 | RAG 적용 후 웹 분석 결과 |
| 평가 항목 | 위험 탐지, 위험도 판단, 법적 근거, 실무 대응, 개선안 |
| 평가 방식 | 반영 / 부분 반영 / 미반영 |

핵심 문장:

> 전문가 수정 및 추가 의견을 기준으로 RAG 적용 전 AI 의견과 RAG 적용 후 AI 분석 결과의 반영 수준을 비교하였다.

## 슬라이드 5. 대표 사례: 중개보수 5% 조항 분석 개선

| 구분 | RAG 적용 전 | RAG 적용 후 |
|---|---|---|
| 위험 탐지 | 법정 요율 초과 가능성 지적 | HIGH 위험으로 명확히 분류 |
| 근거 | 금액 계산 중심 | 법정 요율, 초과 부담, 부가세 문제 설명 |

> RAG 적용 후 AI는 전문가 검토 사례를 반영하여 단순 위험 경고를 넘어 법적 근거, 실무 대응, 수정 조항까지 제시하였다.
